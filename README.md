# CareSphere – Smart Hospital Management System

A student-friendly full-stack hospital management project.

## Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: MySQL
- OOP Core: Modern C++

## Features
- Login
- Dashboard
- Patient management
- Doctor management
- Appointment booking with conflict checking
- Emergency priority management
- Bed management
- Pharmacy stock and low-stock alert
- Laboratory tests
- Billing
- REST API
- MySQL database
- C++ OOP academic core demonstrating inheritance, encapsulation, constructors,
  destructors, static members, friend function, dynamic allocation,
  virtual functions, exception handling, templates and file handling.

## Run backend
1. Install Node.js and MySQL.
2. Create the database using database/caresphere.sql.
3. Open terminal in backend.
4. Run:
   npm install
5. Copy .env.example to .env and change MySQL settings if required.
6. Run:
   npm start
7. Open frontend/index.html with Live Server, or use any static server.

Default demo users:
- admin / admin123
- doctor / doctor123
- patient / patient123

## C++ OOP core
Open cpp/main.cpp in VS Code:
g++ main.cpp -std=c++17 -o caresphere
./caresphere
